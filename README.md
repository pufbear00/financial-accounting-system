# 财务做账系统

这是从已提交源码制作的独立本地副本，不是生产备份包，也没有上传到任何仓库。原项目和原运行数据未改动。

## 包含与不包含

- 保留费用看板、预算与分类、用户权限、月度凭证、累计缺件清单、回单池、多张发票引用及本地 PDF/ZIP 导出代码。
- 不含原数据库、账号、发票/回单附件、真实业务记录、`.env`、密钥、日志、旧 Git 历史、服务器配置和自动部署脚本。
- 首次启动创建独立的 SQLite 空表，仅添加 4 个通用分类；不生成管理员或业务记录。测试中的虚构记录只存在于临时目录，不写入交付文件夹。
- 飞书、支付平台、通讯录、真实汇率、外部附件、评论回传及日报发送均已停用；后端入口返回拒绝，启动时不运行定时同步。界面保留部分对应功能位置供理解结构，但不具备生产联通能力。
- 不读取原 `EXPENSE_*` 环境变量或任何 `.env`，前端仅代理到本机的独立端口，移除了在线字体请求。不要把原系统的配置、数据库或附件复制进来。

## 本地运行

需要已经安装的 Python 3.12、Node.js 与 npm。以下 `python` 仅指已安装的 Python，不要在 macOS 上运行未安装的系统开发工具命令；本文件不会安装 Xcode 或 Command Line Tools。

先在 `backend` 目录创建新的虚拟环境并安装依赖：

```sh
python -m venv .venv
.venv/bin/python -m pip install --only-binary=:all: -r requirements.txt
.venv/bin/python -B -m app.init_demo_admin
.venv/bin/python -B -m uvicorn app.main:app --host 127.0.0.1 --port 8103
```

初始化会请你填写一个全新的本地用户名和密码，密码至少 12 个字符，不要使用公司、飞书或 GitHub 密码。不会记录明文密码。已有管理员时初始化会拒绝覆盖。登录会话密钥每次后端重启重新生成，因此重启后需要重新登录。

另开终端，在 `frontend` 目录运行：

```sh
npm ci --ignore-scripts
npm run dev
```

打开 `http://127.0.0.1:5282`。后端只绑定本机，前端只访问本机 `8103` 端口；不要改成公开监听或公网部署。依赖安装需要访问官方软件包仓库，但应用运行不连接原业务服务。

新创建的数据仅保存在 `backend/runtime/`；该目录不在交付内容中。开始自行填入资料后，这份目录就不再是空数据状态。若需要展示流程，请另外使用自行编造、明确标注的虚构样例，不要恢复原公司资料。
